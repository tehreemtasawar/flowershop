
# Flower Shop Website

A simple and interactive Flower Shop website developed using HTML, CSS, and JavaScript. It allows users to explore different flower bouquets, view their prices, calculate order totals, and fill out an order form for different occasions.

## Features

- **Homepage:** Displays the shop name, welcome message, and flower image.
- **Our Story:** Read More and Read Less functionality.
- **Bouquet Collection:** Displays Gulab Bouquet, Seasonal Mix, and Shaadi Special.
- **Price List:** Displays bouquet prices in a table.
- **Category Filters:** Filter bouquets by Everyday and Wedding categories.
- **Order Total Calculator:** Automatically calculates the total price of selected bouquets.
- **Order Form:** Collects customer details, occasion, add-ons, and special instructions.
- **Discount System:** Displays student and senior discount eligibility based on birth year.
- **Light/Dark Mode:** Allows users to switch between light and dark themes.
- **Opening Status:** Displays whether the shop is open or closed based on the current time.
- **Character Counter:** Displays the remaining characters allowed in special instructions.

## Technologies Used

- CSS3

## How to Run the Project

You can view the live project directly here:

**[View Live Flower Shop Website](INSERT-GITHUB-PAGES-LINK-HERE)**

Alternatively, to run it locally:

1. Clone or download this repository.
2. Open the project folder.
3. Double-click the `index.html` file.
4. The website will open in your default web browser.
5. Explore the different features of the Flower Shop website.

**Note:** For the best experience, use a modern browser like Google Chrome or Mozilla Firefox. An internet connection is required to load the externally hosted flower image.

## GitHub Pages Deployment

This project can be published using GitHub Pages.

1. Open the repository on GitHub.
2. Go to **Settings**.
3. Select **Pages** from the sidebar.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder.
6. Click **Save**.

For detailed instructions, visit the [GitHub Pages Quickstart](https://docs.github.com/en/pages/quickstart).

## Note

The order form currently demonstrates front-end interactions and displays messages in the browser. It does not store or submit actual customer orders to a database.
